# Rust Book figures

These figures accompany the 120 chapters of the Cognitive Engineering Lab’s edition of *The Rust Programming Language*, at Git commit `88250e0392cef0622f318e35469108d68694c1f7`. The 16 SVG figures have been rasterized and the six PNG figures re-encoded as RGBA PNGs. The original files and their license notices are in the pinned [upstream source](https://github.com/cognitive-engineering-lab/rust-book/tree/88250e0392cef0622f318e35469108d68694c1f7/src/img). This distribution includes [the upstream MIT license](LICENSE-MIT).

`catalog.json` records each original Markdown destination, chapter ID, source digest and shipped PNG digest. The release uses resvg 0.49.0 at 1000 pixels wide for SVGs, followed by Pillow RGBA PNG encoding with optimization. The bundled PNG bytes are the portable reference. Font availability during preparation can change rasterized text. resvg reported two invalid ellipse radii in the source drawings and skipped those shapes. Original alt text stays in the admitted chapters.

Operators pin the catalog digest and select this separate figure publication for the original chapter Things. It adds an assets Frontier while preserving the edition and learner identity.
